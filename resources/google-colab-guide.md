# Google Colab Guide

Google Colab can run approved notebooks in a browser when local Python setup is not practical.

- Open only trusted notebooks.
- Make a personal copy before editing.
- Read the first cell and package instructions before running code.
- Remove credentials, private data, and unnecessary outputs before sharing.
- Link a completed notebook from its relevant weekly lesson, not from an unrelated folder.

Colab availability, accounts, and quotas are managed by Google and may change.
