# GitHub Guide

## Essentials

1. Create or sign in to a GitHub account.
2. Fork the repository if you do not have write access.
3. Create a descriptive branch, such as `docs/week-03-notes`.
4. Edit the relevant Markdown file and check links.
5. Commit a focused change and open a pull request.

Read [CONTRIBUTING.md](../CONTRIBUTING.md) for the full workflow. Do not upload private student information or unpublished recordings.
