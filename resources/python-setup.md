# Python Setup

## Recommended local setup

1. Install a supported Python version from the official Python website.
2. Create a project folder and virtual environment: `python -m venv .venv`.
3. Activate it in PowerShell: `.\.venv\Scripts\Activate.ps1`.
4. Install only the packages required by the relevant practical.
5. Keep `.venv/` and `.env` out of Git.

Students who cannot use a local setup may begin in [Google Colab](google-colab-guide.md). Never place API keys, passwords, or private datasets in a notebook.
