## Overview

This supports undergraduate Computer Science students learning Artificial Intelligence. It can grow with the actual departmental sequence rather than imposing a generic machine-learning bootcamp.

## Prerequisites

Basic programming, problem-solving, and introductory discrete-mathematics ideas are helpful. See the [Python setup guide](../../../../resources/python-setup.md).

## Learning outcomes

Subject to lecturer approval, students should be able to explain foundational AI concepts, describe intelligent agents and environments, reason about approaches, document practical work, and discuss ethical implications.
