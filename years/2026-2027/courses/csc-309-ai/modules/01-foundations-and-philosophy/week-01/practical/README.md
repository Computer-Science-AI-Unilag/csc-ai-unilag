# Week 01 Practical: Face Recognition Lab

## Purpose

This practical examines how a machine can recognise a face from image data and where such systems can fail. The supplied notebook builds a classical eigenfaces and nearest-neighbour recogniser, then asks students to investigate the effects of PCA size, nearest-neighbour settings, distance metrics, and decision thresholds.

## Run the notebook

1. Open [face-recognition-lab.ipynb](face-recognition-lab.ipynb) in Google Colab or JupyterLab.
2. Run cells from top to bottom.
3. Use the interactive controls to predict and test the effect of one change at a time.
4. Record observations about accuracy, false accepts, false rejects, and the limits of recognition.

## Responsible use

Face recognition can create privacy, bias, and misidentification harms. Use only the notebook's approved data and never upload personal images or biometric data to a shared notebook without explicit permission.
