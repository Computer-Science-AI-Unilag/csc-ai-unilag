# Student Project Archive

This archive documents approved student projects across academic sessions without requiring the project source code to live here. Larger projects should use their own repository in the organisation or a contributor-owned repository.

## Publishing a project

Use [project-template.md](project-template.md) for each approved entry. Include a problem statement, session, course, technologies, repository/demo links, status, and public contributor credits only where consent is clear.
