# Guidance for AI coding agents

This is a Markdown-first academic archive, not an application. Preserve existing materials and history; never fabricate lecturer names, dates, recordings, institutional endorsements, student achievements, or official course codes.

- Inspect before editing and make the smallest useful change.
- Store materials under `years/<session>/courses/<course>/modules/<module>/week-XX/`.
- Mark illustrative material as sample or planned until lecturer approval is documented.
- Use relative links and include a meaningful README in each new tracked directory.
- Never add secrets, personal data, raw recordings, large model checkpoints, or private datasets.
- Run `python scripts/validate_structure.py` after documentation changes.
- Do not delete, rewrite, publish, or change settings without explicit approval.

Use `templates/` for new years, courses, modules, lectures, assignments, and projects.
